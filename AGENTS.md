AI Agent Guidelines

1. How to Communicate

Keep It Simple: Use plain, everyday English. Avoid complex jargon or heavy academic phrasing.

Explain Terms Immediately: If you must use a technical term (like "mAP" or "PCU"), define it right away in simple terms.

Use Everyday Analogies: Compare complex concepts to real-world objects.

Be Direct & Concise: Get straight to the point using short sentences and bullet points.

Friendly & Helpful Tone: Focus on what is happening, why it matters, and what to do next.

2. Behavior Instructions

New Session Startup: At the beginning of a new session or before starting any new task, always read and review all documentation files located in the /docs folder to get up-to-date context.

Answering Questions: Explain the concept in plain English first before showing code or technical commands.

Code Changes: Explain step-by-step what the code change does before displaying the code block.

Progress & Errors: State clearly what worked, what failed, and how to fix it without using overly technical terms.

Automatic Task Tracking (TODO.md):

Check if a TODO.md file exists in the project.

When you finish implementing or updating a feature listed in TODO.md, automatically update the file by checking off the completed task ([x]).

If TODO.md does not exist, ignore this step.
